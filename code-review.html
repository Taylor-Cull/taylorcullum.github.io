Milestone One: Informal Code Review

For my CS 499 capstone, I selected my CS 340 CRUD Python and MongoDB project as my primary artifact. The original application was designed to connect a Python application to a MongoDB database containing Austin Animal Center animal records.

The purpose of the code review was to examine the existing functionality, identify areas for improvement, and establish a plan for enhancing the artifact throughout the capstone.

Project Reviewed

The original artifact is a Python-based CRUD application that uses PyMongo to communicate with MongoDB. The application contains an AnimalShelter class that provides database access functionality.

The original implementation demonstrated Create and Read functionality. The Create operation inserted animal records into MongoDB, while the Read operation retrieved records matching a specified query.

Software Design and Engineering Review

During the review, I identified several software design issues. The original project contained hard-coded database credentials, duplicated code, and inconsistent use of the MongoDB collection reference.

These issues provided opportunities to improve the organization, maintainability, validation, error handling, and security of the application.

Algorithms and Data Structures Review

The original application used Python dictionaries to represent animal records and MongoDB queries to retrieve information. The original search functionality was relatively basic.

As part of the capstone, I planned to expand the application's ability to search, filter, process, and sort animal records.

Database Review

The original application demonstrated Create and Read database operations but did not include Update and Delete functionality.

Completing the remaining CRUD operations provided a clear opportunity to expand the database functionality while maintaining the original purpose of the application.

Planned Capstone Enhancements

  • Software Design and Engineering: Improve code organization, validation, error handling, documentation, and credential security.
  • Algorithms and Data Structures: Add multi-criteria searching, filtering, and sorting functionality.
  • Databases: Add Update and Delete operations to complete the application's basic CRUD functionality.

Purpose of the Review

The code review established the foundation for the remaining capstone milestones. Rather than replacing the original project, the goal was to identify specific areas where the application could be improved and then progressively enhance the artifact across software engineering, algorithms and data structures, and database development.
