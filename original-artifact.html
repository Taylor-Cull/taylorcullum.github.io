CS 340 Original Project

My selected capstone artifact was originally developed for CS 340: Client/Server Development. The project is a Python-based CRUD application that connects to a MongoDB database containing Austin Animal Center animal records.

The original project provided the foundation for my CS 499 capstone enhancements. Rather than replacing the original application, I used the existing project as a starting point and progressively improved it in software design and engineering, algorithms and data structures, and database development.

Project Information

Course: CS 340 – Client/Server Development

Project: Animal Shelter CRUD Application

Programming Language: Python

Database: MongoDB

Database Driver: PyMongo

Development Environment: Jupyter Notebook

Purpose of the Application

The purpose of the original application was to provide a reusable Python module for communicating with a MongoDB database. The application was designed around an AnimalShelter class that handled database access.

The database contained animal records from the Austin Animal Center. The application allowed Python code to communicate with MongoDB and perform basic database operations on those records.

Original Functionality

The original project demonstrated the Create and Read portions of CRUD functionality.

Create

The Create functionality used MongoDB's insert_one() operation to add a new animal record to the database.

Read

The Read functionality used MongoDB's find() operation to retrieve records matching a specified query.

Data Structure

Animal records were represented using Python dictionaries containing key-value pairs such as animal ID, name, animal type, breed, color, and outcome information.

Original Code Structure

The main component of the original application was the AnimalShelter class. The class was responsible for establishing the MongoDB connection and providing methods for database operations.

The original implementation provided a useful foundation, but the code review identified several areas where the application could be improved. These areas included code organization, credential security, validation, error handling, search functionality, and incomplete CRUD functionality.

Why I Selected This Artifact

I selected this project because it provided opportunities to demonstrate growth across all three required CS 499 enhancement categories.

  • Software Design and Engineering: The original code could be reorganized and improved for maintainability, validation, error handling, and security.
  • Algorithms and Data Structures: The original search functionality could be expanded with multi-criteria searching, filtering, and sorting.
  • Databases: The original project demonstrated Create and Read operations but provided an opportunity to add Update and Delete functionality.
