Introduction

Throughout my Bachelor of Science in Computer Science program, I have developed a broad understanding of software development, programming, databases, algorithms, security, and technical problem-solving. My coursework has challenged me to approach problems from different perspectives and has helped me develop skills that I can apply to real-world technology environments. Creating my CS 499 ePortfolio has provided an opportunity to bring those skills together and demonstrate how my abilities have developed throughout the program.

One of the most valuable aspects of the program has been learning how different areas of computer science work together. Programming is not only about writing code that works; it also requires consideration of usability, maintainability, security, data management, efficiency, and communication. My capstone project allowed me to apply these concepts to an existing project and progressively improve it.

Collaboration and Communication

Throughout my coursework, I have developed experience communicating technical information and working through problems in environments where clear communication is important. Group assignments and project-based coursework helped me understand the importance of explaining technical decisions and considering the needs of different stakeholders.

The CS 499 code review further developed these skills because I had to explain an existing software project, identify areas for improvement, and communicate my enhancement plans in a professional manner. Rather than simply showing that the code worked, I had to explain why specific changes were necessary and how those changes would improve the application.

Software Design and Engineering

Software design and engineering have become important parts of my development as a computer science student. Through my coursework, I learned that software should be designed with maintainability, organization, reliability, and usability in mind.

For my CS 499 artifact, I enhanced my original CS 340 Python and MongoDB project by improving the structure of the AnimalShelter class, removing duplicated code, adding input validation, improving error handling, and improving how database credentials are handled. These changes helped me understand that improving an existing application involves more than adding new features.

Algorithms and Data Structures

My coursework also helped me develop a stronger understanding of algorithms and data structures and their role in solving computing problems. I learned how the organization and processing of information can affect the efficiency and usefulness of an application.

For my capstone artifact, I expanded the original database application by adding multi-criteria search and sorting functionality. The enhancement uses Python dictionaries to represent search criteria and lists to process and organize returned records. This allowed me to apply concepts involving searching, filtering, sorting, and data processing to an existing application.

Databases

Database development has been another important area of my computer science education. My CS 340 project gave me practical experience working with MongoDB and PyMongo and helped me understand how applications communicate with databases.

For my capstone, I expanded the original Create and Read functionality by implementing Update and Delete operations. This resulted in a more complete CRUD application that can create, retrieve, modify, and remove records.

Security

Security has also become an important consideration in how I approach software development. Throughout my coursework, I learned that security should be considered during the design and development process rather than treated as something added at the end.

One example from my capstone was identifying the use of hard-coded database credentials in the original application. I improved the application by allowing credentials to be supplied through parameters or environment variables rather than requiring sensitive information to remain directly in the source code.

Professional Goals

My computer science education has expanded my professional interests and given me a stronger foundation for pursuing technology-focused opportunities. My background in healthcare and pharmacy has also helped me recognize the value of combining technical knowledge with knowledge of healthcare operations.

I am particularly interested in opportunities where technology can be used to improve healthcare processes, data management, patient services, and organizational efficiency. My experience with programming, databases, data analysis, and healthcare workflows gives me a foundation for working at the intersection of technology and healthcare.

Capstone Artifact and Portfolio

My CS 340 CRUD application represents the progression of my technical skills throughout the capstone. The original project provided a foundation using Python, MongoDB, and PyMongo. I then enhanced the artifact in three areas: software design and engineering, algorithms and data structures, and databases.

The software engineering enhancement improved the structure, validation, error handling, documentation, and security of the application. The algorithms and data structures enhancement expanded the application's ability to search, filter, and sort animal records. The database enhancement completed the CRUD functionality by adding Update and Delete operations.

Conclusion

Completing the Computer Science program and developing my CS 499 ePortfolio has helped me recognize how much my technical skills have grown. I have developed experience with programming, software engineering, algorithms and data structures, databases, security, and technical communication.

More importantly, I have learned how these areas connect when developing a complete computing solution. My capstone demonstrates that growth by showing the progression from an original project to an enhanced application with improved software design, expanded data processing capabilities, and complete database functionality.

I plan to continue building on these skills throughout my career by learning new technologies, strengthening my technical abilities, and looking for opportunities to use computer science to solve practical problems.
