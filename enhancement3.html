Database Enhancement

The third enhancement to my CS 340 artifact focused on database functionality. The original application demonstrated Create and Read operations using Python, PyMongo, and MongoDB. For this enhancement, I expanded the application by implementing the remaining Update and Delete operations.

Enhancement Focus

  • Update database records
  • Delete database records
  • Input validation
  • MongoDB database operations
  • PyMongo error handling
  • Complete CRUD functionality

Original Database Functionality

The original application provided Create and Read functionality. The Create operation allowed animal records to be inserted into MongoDB, while the Read operation retrieved records based on a supplied query.

Update and Delete operations were not originally implemented. Adding these operations provided an opportunity to make the application a complete CRUD solution.

Complete CRUD Functionality

Create

Adds a new animal record to the MongoDB collection.

Read

Retrieves animal records that match a specified query.

Update

Modifies information contained in an existing animal record.

Delete

Removes a selected animal record from the database.

Update Functionality

I added an update() method that accepts a query identifying the record that should be modified and an updates dictionary containing the new information.

The method uses MongoDB's update functionality to modify the selected document without replacing the entire record.

Input validation was also added to make sure that both the query and update information are provided as non-empty dictionaries.

Delete Functionality

I added a delete() method that accepts a query identifying the record to remove.

The method uses MongoDB's delete operation to remove one matching document from the collection. The method also validates the query before attempting the database operation.

Error Handling

Both the Update and Delete operations include PyMongo error handling. If a database error occurs, the application reports the problem rather than allowing the exception to terminate the program unexpectedly.

The methods also return a Boolean result indicating whether a record was successfully modified or deleted.

Testing

I tested the enhanced database functionality by updating a test animal record and then reading the record to verify that the change was successful. I also tested the Delete operation and verified that the selected test record was no longer returned by the database query.

Combined with the previous software engineering and algorithms enhancements, this database enhancement demonstrates the progression of my original CS 340 project into a more complete computing solution.
