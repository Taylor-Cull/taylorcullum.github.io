Algorithms and Data Structures Enhancement

The second enhancement to my CS 340 artifact focused on algorithms and data structures. After reviewing the original application, I identified an opportunity to improve how animal records could be searched, filtered, processed, and organized.

Enhancement Focus

  • Multi-criteria searching
  • Dictionary-based search criteria
  • List-based result processing
  • Filtering database results
  • Sorting returned records
  • Input validation

Original Functionality

The original application provided basic Read functionality through MongoDB queries. A query could be supplied to retrieve matching animal records, but the application did not provide a dedicated method for combining multiple search criteria and organizing the returned results.

This created an opportunity to expand the application's data processing capabilities while maintaining the existing MongoDB structure.

Multi-Criteria Searching

I added a new search_animals() method that accepts multiple search criteria through a Python dictionary.

Using a dictionary allows multiple field and value pairs to be supplied as search criteria. For example, a user can search for records using an animal type and outcome at the same time.

Data Structures

The enhancement uses Python dictionaries to represent search criteria and Python lists to store and process the records returned from MongoDB.

These structures allow the application to organize information in a way that can be easily processed by the Python program.

Filtering and Processing

The search method passes the supplied criteria to MongoDB and converts the returned records into a Python list. This provides a collection that can be processed and organized before being returned to the user.

The method also validates the search criteria before performing the database operation. This helps prevent invalid search data from being passed to the application.

Sorting

I added optional sorting functionality that allows returned animal records to be organized according to a selected field. The user can specify the field used for sorting and choose ascending or descending order.

This makes the results easier to analyze and provides additional flexibility when working with larger sets of animal records.

Example

A search can provide multiple criteria and then sort the results by a selected field.

Example search criteria:

Animal Type: Dog
Outcome: Adoption

The returned records can then be sorted by another field, such as breed.

Skills Demonstrated

  • Searching and filtering

  • Data processing

Reflection

This enhancement helped me better understand how algorithms and data structures can improve the functionality of an existing application. Rather than simply retrieving records, the application can now process search criteria and organize returned information in a more useful way.

The enhancement also reinforced the importance of selecting appropriate data structures based on the type of information being processed. Dictionaries provide an effective way to represent search criteria, while lists provide a flexible structure for processing returned records.

This enhancement builds on the software design improvements from Enhancement 1 and provides a stronger foundation for the final database enhancement.
