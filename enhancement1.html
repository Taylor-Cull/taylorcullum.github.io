Software Design and Engineering Enhancement

The first enhancement to my CS 340 artifact focused on software design and engineering. After reviewing the original application, I identified several areas that could be improved, including code organization, input validation, error handling, maintainability, and security.

Enhancement Focus

  • Improved object-oriented design
  • Improved code organization
  • Input validation
  • Error handling
  • Improved documentation
  • Improved credential security

Original Design Issues

The original application contained database credentials directly in the Python source code. The original module also contained duplicated code within the Create functionality and did not consistently use the collection reference created during the database connection.

These issues made the application less maintainable and created opportunities to improve its reliability and security.

Improved Class Design

I improved the AnimalShelter class so that database connection information can be supplied through parameters or environment variables. This makes the class more reusable and prevents sensitive credentials from being directly embedded in the source code.

The enhanced class also provides clearer documentation explaining the purpose of the class, its methods, and the information each method expects.

Input Validation

The enhanced application includes additional validation before database operations are performed.

The Create method verifies that the supplied data is a non-empty Python dictionary. The Read method also verifies that the supplied query is a dictionary before attempting to search the database.

These checks help prevent invalid information from being passed directly to the database operations.

Error Handling

I improved the application's error handling by using PyMongo's database error handling capabilities. Database operations are placed inside exception-handling blocks so that database errors can be reported without unnecessarily terminating the application.

The enhanced Create and Read methods also return consistent results when operations succeed or fail.

Security Improvements

Security was an important part of this enhancement. The original project contained a database password directly in the source code. I changed the application so that credentials can be provided through parameters or environment variables.

This reduces the possibility of accidentally exposing sensitive database credentials when sharing or publishing the source code.

Skills Demonstrated

  • Python object-oriented programming
  • Code organization and maintainability
  • Input validation
  • Exception handling
  • MongoDB and PyMongo integration
  • Secure handling of credentials
  • Technical documentation

Artifact

The enhanced Python module demonstrates the changes made during this milestone. The enhanced artifact maintains the original purpose of the application while providing a stronger foundation for the remaining capstone enhancements.

Reflection

This enhancement helped me understand that software engineering involves more than adding new features. Improving structure, validation, documentation, error handling, and security can make an existing application significantly easier to maintain and expand.

The improvements made during this milestone provide the foundation for the algorithms and database enhancements completed later in the capstone.
